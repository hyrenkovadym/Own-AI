# Roadmap

## Near-Term Improvements
- Better training metrics:
  - add per-episode exports and richer aggregation options
- Charts for learning progress:
  - score trends, epsilon decay, win rate
- Improved reward tuning:
  - systematic experiments for shaping and stability
- Better chat dataset:
  - expand intent coverage and phrase diversity

## Mid-Term Improvements
- More ML models:
  - alternative intent classifiers and Snake agent variants
- Plugin/module interface improvements:
  - clearer module contracts and versioned interfaces
- Packaging as a Python package:
  - installable package and cleaner CLI entry points
- Better GUI visualization:
  - richer live analytics and model diagnostics

## Quality & Engineering
- More test coverage:
  - broader module tests, regression tests, and edge-case validation
- More CI checks:
  - linting/type-check options and smoke integrations
- Documentation expansion:
  - experiment recipes and tuning playbooks
